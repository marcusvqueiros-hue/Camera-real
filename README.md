# Câmera Real

App web instalável (PWA) para Android e iPhone que grava data, hora e localização na própria foto, guarda as fotos no celular quando não há internet e envia tudo para o Supabase (banco `photos` + armazenamento privado `fotos`) quando a conexão volta. Tem galeria por dia e botão para baixar a foto no aparelho.

Link de teste: https://raw.githack.com/marcusvqueiros-hue/camera-real/main/index.html
